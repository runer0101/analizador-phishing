Analizador de phishing

Lee el enlace como texto y te dice qué señales de fraude tiene. No lo visita, no lo envía a ningún servidor y no necesita internet.

Analiza un enlace

El análisis ocurre en tu navegador, con WebAssembly. El enlace no sale de tu equipo.

Casos de la demostración

Pulsa uno y verás el veredicto al instante. El cuarto caso es un sitio real: el analizador lo marca y por qué se lo decimos.

    subdominios    		1Cuatro o más etiquetas: el dominio de verdad está al final
    Letras camufladas
    letras_camufladas    		2Punycode (xn--) o letras no latinas que imitan a las verdaderas
    Link acortado
    acortador    		2Acortadores que esconden el destino real
    Terminación poco confiable
    terminacion_rara    		1Terminaciones baratas (.xyz, .top, .tk…)
    Muchos guiones
    guiones    		1Dominios con tres o más guiones: patrón habitual de suplantación
    Palabra de gancho
    palabra_gancho    		1login, clave, verificar, urgente…
    Usa el nombre de una marca
    marca_falsa    		3Usa el nombre de una marca conocida y no es el sitio oficial
    Imita a una marca
    typosquatting    		3Un solo cambio de diferencia: letra de más, de menos, cambiada o letras parecidas

    5+ puntos → ALTO · 3-4 → MEDIO · 0-2 → BAJO. Un veredicto no es una sentencia: es una señal de que el enlace merece revisión humana.

    Limitaciones

    El analizador mira solo la dirección, sin abrir el enlace. Eso tiene un precio:

    • Falsos positivos: un sitio legítimo puede sumar puntos. Un banco real con verificacion en la ruta o con muchos guiones sale como sospechoso, aunque sea de fiar.
    • Falsos negativos: un phishing con dominio nuevo, limpio y corto puede salir en verde. Ninguna lista de reglas cubre todos los casos.
    • No ve la página: un formulario falso dentro de facebook.com real no se detecta aquí.
    • No comprueba nada fuera del enlace: quién lo envía, a qué hora y desde dónde se requeriría revisar el correo y el servidor de correo, no solo la URL.

    Por eso la conclusión correcta no es «esto es phishing», sino «esto merece revisión humana».

    Marcas vigiladas

    Cuando el dominio usa el nombre de una de estas marcas pero no es el sitio oficial, el analizador suma 3 puntos:

    • PayPal paypal.com
    • Google google.com
    • Facebook facebook.com
    • WhatsApp whatsapp.com
    • Microsoft microsoft.com
    • Amazon amazon.com
    • Apple apple.com
    • BCP bcp.com.bo
    • BNB bnb.com.bo
    • Banco Unión bancounion.com.bo
    • Mercantil Santa Cruz mercantilsantacruz.com.bo
    • Banco Estado bancoestado.com.bo

    El programa de terminal

    La misma herramienta se puede instalar y usar sin navegador. Hay binarios para:

    • Linux (x86-64 y ARM64) — archivo phishing-analyzer-linux-x86_64
    • macOS (Intel y Apple Silicon) — phishing-analyzer-macos-aarch64
    • Windows (x86-64) — phishing-analyzer-windows-x86_64.exe

    Cómo se usa:

    # la demostración completa, con los cinco casos
./phishing-analyzer-linux-x86_64 --demo

# un enlace suelto
./phishing-analyzer-linux-x86_64 "http://paypa1.com/login/verify"

# una lista de enlaces, uno por línea
./phishing-analyzer-linux-x86_64 --file enlaces.txt

# salida JSON para integrarlo con otro sistema
./phishing-analyzer-linux-x86_64 --json "https://www.google.com"

    Descargas, con sus sumas SHA-256, en la release v0.3.0. En Windows se ejecuta con phishing-analyzer-windows-x86_64.exe --demo.
