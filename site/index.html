Analizador de phishing

Lee el enlace como texto y te dice qué señales de fraude tiene. No lo visita, no lo envía a ningún servidor y no necesita internet.

Analiza un enlace

El análisis ocurre en tu navegador, con WebAssembly. El enlace no sale de tu equipo.

Casos de la demostración

    Las once señales

    SeñalPuntosDetecta
    no_https1El enlace no usa HTTPS
    ip_host2Una IP en vez de un dominio con nombre
    userinfo2El «@» que esconde el destino real
    deep_subdomain1Cuatro o más etiquetas en el dominio
    punycode2Letras camufladas (xn--)
    shortener2Acortadores que esconden el destino
    suspicious_tld1Terminaciones baratas (.xyz, .top…)
    hyphen_chain1Dominios con tres o más guiones
    hook_words1Palabras de gancho: login, clave, verificar…
    brand_impersonation3Usa el nombre de una marca y no es el sitio oficial
    typosquat3Imita una marca cambiando una letra (paypa1.com)

    5+ puntos → ALTO · 3-4 → MEDIO · 0-2 → BAJO. Un veredicto no es una sentencia: es una señal de que el enlace merece revisión humana.

    Herramienta propia escrita en Rust, sin dependencias externas. Código e historial · Descargar el binario · Esta demo

    Material para un laboratorio controlado y autorizado. El analizador no abre ninguna conexión: solo analiza el texto del enlace que tú le entregas.
